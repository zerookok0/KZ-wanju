Как установить

30 сек
  1. Нажми «Скачать»

    Начнётся загрузка файла.

  2. Открой файл из уведомления или из «Файлов»

    Файл app-latest.apk лежит в папке «Загрузки».

  3. Разреши установку из неизвестных источников

    Настройки → Приложения → Специальный доступ → Установка неизвестных приложений → включить.

  4. «Установить» → «Открыть»

    Займёт несколько секунд.
